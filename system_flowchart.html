Capacity-Aware Early-Warning Flow

How each OULAD enrolment moves from checkpoint data to a calibrated risk score, a conformal prediction set and a routed action under fixed staff capacity. The routing block follows the rules in routing_engine.py.

Process Decision Candidate for a place Waiting (no place) Status set directly by the route

Partitions are whole module presentations, and each student appears in one partition only. The routing block shows the proposed method. The five reference methods (rule-based alerts, Top-K, threshold deferral, conformal without persistence, conformal without separate Waiting) share the same capacity limits and repeat-selection rules. Review places go to new candidates first; a contacted student still at p ≥ 0.5 gets a follow-up Review only from places left over.
